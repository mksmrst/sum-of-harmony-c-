# Ответ на задание
_Float хранит только 7 значащих цифр. При прямом порядке (от 1 к N) сумма быстро становится большой (~15), и когда мы прибавляем маленькие числа (0.0000001), они не влезают в 7 цифр и отбрасываются. Сумма перестаёт расти.
При обратном порядке (от N к 1) мы сначала складываем маленькие числа между собой. Они не теряются, потому что все одного размера. Потом маленькие превращаются в большие, и мы складываем большие с большими. Ничего не теряется.
Поэтому обратный порядок точнее._
